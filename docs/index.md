# Guia Prático de Controladores Lógicos Programáveis (CLP)

Guia técnico de estudo sobre CLPs e automação industrial, com foco prático: referência de instruções, exemplos testados, projetos e comparação entre fabricantes. Plataforma principal: **CODESYS** (IEC 61131-3).

Este guia complementa o material teórico da disciplina de Automação de Sistemas Industriais. Aqui, o objetivo é a aplicação.

Use o menu lateral para navegar pelos capítulos. As fontes citadas estão em [Referências](99-referencias/index.md).
